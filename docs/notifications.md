# 通知与校园快捷方式（0.4.1）

“我的 → 通知”有三个独立开关：下节课提前提醒、每日早报、API 消息。首次开启请求 Android 通知权限。课前提醒可提前 5/10/15/30/60 分钟，早报时间可选；依据当前账号缓存课表、学期起始周和课程周次计算。课表导入、同步、学期修改与切换账号都会重新安排。重启设备后系统接收器恢复已安排通知。允许精确闹钟可提高准时性；Android 省电策略、强制停止等仍可能影响投递。

## 接入消息 API

填 HTTPS 地址与可选 Bearer 令牌，保存后开启 API 消息。客户端不跟随接口重定向，避免令牌发送到其他域名。配置使用本机安全存储，Android 后台配置用 Keystore AES-GCM 加密。不要将令牌提交到仓库。

服务器处理 `Accept: application/json` 时返回以下任一格式：

```json
{"messages":[{"id":"notice-20261006-001","title":"校园消息","body":"消息内容","url":"https://example.edu.cn/notice/1"}]}
```

也支持消息数组或单个消息对象。id 必须稳定，同一个通知不要每次更换 id。最近 200 个 id 在本机去重；每个响应最多 200 条消息、1 MiB。url 可选，点击可用浏览器打开有效 HTTPS 页面。

开启 SSE 时，同一地址处理 `Accept: text/event-stream`，返回标准 SSE，每条 data 为单个 JSON 消息，空行结束事件：

```text
data: {"id":"notice-001","title":"校园消息","body":"内容"}

```

前台 SSE 保持连接，断开后 10 秒重连；未开启 SSE 时前台每 30 秒检查 JSON。后台 WorkManager 最短 15 分钟定期检查 JSON，实际时间受系统调度影响。SSE 服务须同时提供 JSON 快照。后台不是持续 SSE，也未接入厂商推送；如果要求应用退出后秒级到达，需要另行提供推送服务和对应应用凭据。

“立即检查 API”可验证配置；“发送测试通知”可验证系统通知权限。

## 快捷方式

首页提供学习通、雨课堂、钉钉、企业微信默认入口。“我的 → 校园快捷方式”支持选择已安装应用、手动输入包名、添加 HTTPS 或 weixin:// 链接、修改和删除。未安装或链接失效会显示错误。

雨课堂默认打开官方网页。微信小程序须使用其提供的有效 URL Link/唤起链接；编辑雨课堂入口替换即可。不内置未经验证的 appid/path 或临时链接。微信分享的 `#小程序://…` 展示文本并非可直接被 Android Intent 唤起的 URL，需取得实际链接。

## 地图

地图使用高德官方 URI API，不需要用户申请 JS 地图 Key。所有保存点和 GPS 定位使用 WGS84，并通过 `coordinate=wgs84` 声明坐标系统。“用地图软件打开”支持高德、百度和系统地图选择；安装腾讯地图等支持 geo Intent 的地图也可由系统选择。标签支持当前位置添加、手动坐标与删除。地图需要网络连接。
